# OUT-32 performance contract and evidence

The current product exposes chats, diffs, provider choices, and worktree navigation. Native workflow history, event inbox, review chapters, and role output have no UI or persistence path on this branch; their future owners must apply the same bounded view and state rules when those surfaces arrive. OUT-30 owns backend quotas.

| Surface and owner | Main risk | Contract and focused evidence |
| --- | --- | --- |
| Chat history in `src/App.jsx`, `src/components/WindowedMessages.jsx`, `src/recovery-policy.js`, `server/database.mjs`, and `server/outright-runtime.mjs` | Pagination, late events, resizing, or recovery moves the reading anchor; offscreen and older messages become unfindable | Keep at most 1,000 client messages, 2,048 checkpoint cursors, 20 tool events, and a 2 MiB pending event buffer. A 1,000-message fixture mounts fewer than 40 rows, scrolls to both ends in under 1 s, finds matches near both ends, and preserves the anchor on prepend. Conversation-scoped find returns at most 200 persisted rows around a match; next/previous wrap through older pages. A 10,000-event replay completes under 250 ms and returns the newest 1,000. |
| Git diff and mutations in `src/components/ChangesPane.jsx`, `src/components/WindowedDiff.jsx`, and `server/git-service.mjs` | The real inspector lets the diff viewport grow to full text height; stale stage, unstage, commit, status, or diff completion crosses a worktree switch | The 448 px production column bounds a 50,000-line staged and unstaged diff below 200 mounted spans, retains visible mode controls, reaches the final line by wheel and End key, and marks an offscreen find match. A 320 px inspector remains bounded. Mutation completion is fenced by worktree generation before a refresh, toast, error, or state commit. The existing 12 MiB Git command output bound still applies. |
| Provider discovery in `server/provider-discovery.mjs`, `src/App.jsx`, and `server/outright-runtime.mjs` | A missing CLI remains falsely unavailable after install; a checking bootstrap misses its only event; trust is revoked during the provider await | Cache probes outside requests with one in-flight refresh, 2.5 s process timeout, 30 s refresh interval, and shutdown cleanup. Negative authorization retries immediately, including when a stale probe was already in flight. A checking bootstrap polls until settled. Send and recovery recheck trust just before their durable commits, along with target identity and recovery order. |
| Worktree navigation and live output in `src/App.jsx` | Repeated switches mount hidden chats or every delta repaints the root | A 200-worktree fixture switches eight times under 3 s, keeps one conversation mounted, and returns an input frame under 250 ms. A 200-delta fixture preserves all output, bounds paints by elapsed stream time at a 24 ms cadence plus eight frames (at most 100), and returns an input frame under 250 ms. Assistant delta painting is coalesced at 32 ms while checkpoint and final messages flush immediately. |

Sibling operations and state changes considered: chat selection, older-page prepend, return to latest, WebSocket replay, staged/unstaged and file changes, stage/unstage/commit success and failure, recovery retry/resume/discard, trust grant/revoke, provider install/removal, and shutdown during a probe. Malformed find queries and foreign message cursors fail before page navigation; unknown providers remain unavailable. Concurrent search and mutation responses are fenced to the selected conversation or worktree. The runtime owns authorization and durable run state; the database owns bounded page retrieval; the view components own DOM windowing and keyboard navigation. Provider probing uses `execFile` on macOS, Linux, and Windows with `windowsHide`; Windows/Linux launch and process cleanup differ and remain covered by their existing targeted tests and static review. Native workflow history, event inbox, review chapters, and role output are absent on this branch, so their future owners must apply this contract when those surfaces are built.

Latest full browser fixture on Mac16,7 with Node 22.22.1 and headless Chrome: 1,000-message navigation and find in 398 ms with 10 initial rows; 50,000-line diff navigation in 102 ms with 66 mounted spans; 200 deltas in 2,225 ms with 44 paints against a rate-adjusted budget of 100 and a 13 ms input frame; eight switches across 200 worktrees in 686 ms with one mounted conversation and a 72 ms input frame. The heap reading before and after worktree switches was 78.9 MiB and 77.5 MiB; garbage collection makes this a trend sample, not a deterministic gate. A live `/api/providers` sample on the running preview measured 0.22 ms median and 1.45 ms p95 across 50 requests. The fixtures do not prove multi-hour memory stability or manual spoken screen-reader behavior; the latter remains deferred to OUT-45.
